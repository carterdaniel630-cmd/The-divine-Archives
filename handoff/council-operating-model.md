# Council Operating Model — The Divine Archives

Codified 2026-10-16 (S5, S6). This is the single council system. The old weekly crews are retired, not merged.

## The model (Carter 2026-10-15, standing)

A goal goes to SEPARATE, ISOLATED agents, each with a distinct personality/prompt (e.g., Budget Expert, Safety & Logistics Auditor, Local Experience Guide). Each researches INDEPENDENTLY (own browser, own findings). They submit to a separate CONVENER agent, who aggregates, highlights where they disagree, and writes ONE balanced Advisory Brief for Carter to review and click Approve. No single agent ventriloquizing multiple councils. Carter is the approver.

## The three rules (injected into every council agent)

1. **FIRST-PRINCIPLES THINKING:** no copy-pasting first search results or generic summaries; strip to foundational facts, build logic from scratch.
2. **SHOW THE SCRATCHPAD:** step-by-step chain-of-thought, Fact A → Conclusion B, no jumping to answers.
3. **SELF-CRITIQUE LOCK:** before submitting to the Convener, each agent red-teams itself: "The weakest part of my plan is X, and the edge case that breaks my logic is Y."

**CONVENER:** must NOT blend into generic compromise — must show a DIVERGENCE MATRIX mapping exactly where the experts fiercely disagree and why, so Carter sees raw trade-offs before deciding.

## See-first rule (Carter 2026-10-16, S6)

Councils must see what they represent before convening — but the enforceable standard is **capture-verified + named verifier**, not live-browser-on-every-cycle (which bottlenecks on a single delegation path and cannot be done by background workers at all).

- Every council brief must carry a see-first attestation: what live artifact was seen (URL / file / post), via what capture (screenshot / recording / frame), verified by whom (named).
- No brief without an attestation.
- The capture must be of the LIVE artifact itself — never a mockup, a description, or a brief.
- Live-browser checks (via delegation) are still used when available for the highest-stakes verifications. Capture-verified is the floor, not the ceiling.

## Brief preservation (rule, 2026-10-16)

Every full specialist brief is saved to a dated file BEFORE convening. The
Convener cites the file paths and confirms the brief count before
aggregating. No brief survives only via summary. (This fixes the 2026-10-15
loss, where 25 of 26 briefs survived only via a consolidated summary and the
originals were unrecoverable.)
