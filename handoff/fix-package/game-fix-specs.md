# Game Fix Specs — for Claude Code

Specs only. Do NOT rebuild from this file alone — Claude does the rebuilds,
so the work is done once. Nothing here merges to main without Carter's
explicit go-ahead.

## Standing rule — all games

Games must be FUN and ENGAGING, with PLENTY OF DETAIL. Board games must
look and play like board games — enjoyable as board games — with a
mystical/ethereal feel matching the tradition they came from. Physical
games (for example the Mesoamerican ballgame) are digital 3D walkthrough
spaces, not board games. The Mesoamerican ballgame is PARKED — mechanics
complicated, not starting now.

---

## Divine Casualties — "War of the Gods"
(Carter calls it "divine warfare" / "ungodly warfare" — same game.)

- **What is wrong (Carter, in his words):** The mechanics are STIFF and
  the controls are TOUCHY.
- **Fix:** Loosen and retune movement and combat feel. Smooth the
  controls — no jerky, oversensitive, or unresponsive inputs. Every
  action should feel deliberate and readable: the player always knows
  what happened when they pressed something.
- **Feel standard:** Measure against the approved hit-feel sets — Punchy
  Hits (flash, sound, particles, knockback, shake + freeze), Magic
  Attacks (charge, core, trail, burst, reaction, sound, aftermath,
  damage numbers), and the Gunfire adaptation (arrows/spears/bolts,
  subtle impact, broken shafts/embers, body-throw defeat). Those sets
  are already approved; the fix is making Divine Casualties actually
  deliver them.
- **Verify on the phone first.** Carter plays and reviews on his phone.
  If it feels stiff or touchy there, it is not fixed.

## Tomb Robber

- **What is wrong (Carter, in his words):**
  1. The character is SO SMALL you can barely see it.
  2. One spikes obstacle is TOO LONG — there is no way to get enough
     speed to jump clear across it. The spikes were stretched out too
     far.
- **Fix:**
  1. BIGGER character. Bigger, readable buttons and obstacles. Everything
     on screen clearly visible — the player must be able to see the
     character, the buttons, and the obstacles at a glance, on a phone
     screen.
  2. SHORTEN the spikes so the jump is possible. Then audit EVERY jump
     and gap in the game: every jump must be possible with the speed
     the player can actually build. No impossible jumps anywhere.
- **Verify on the phone first.** If anything on screen is hard to see,
  it is not fixed.

## All other games

Same bar: fun, engaging, plenty of detail. Board games look and play
like board games. Every game gets the weekly detail pass (see
weekly-detail-pass-program.md). Any game with an impossible jump, an
unreadable button, or a character too small to see gets the Tomb Robber
treatment: make it visible, make it possible, make it feel good.
