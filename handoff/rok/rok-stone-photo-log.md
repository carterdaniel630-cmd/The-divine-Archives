# Rök Stone page — photograph log (staged to the loop 2026-11-09)

Staged by atlas under the Rök page follow-on Carter commissioned 2026-11-06:
place these photographs on the live Rök page with their attribution and
share-alike credits. All licences below were read on the actual Wikimedia
Commons file pages. The live page's own promise names five faces; FOUR of
the five are licence-verified below, plus detail and hero shots. The second
narrow side is honestly still open — see "Honest gaps". Do not caption any
photo as a face it is not verified to show.

Page: https://www.getconexto.com/vault/rok-runestone-decoded.html (live, PR #127)
Live page promise (read on the live page 2026-11-08): "Photographs of the five faces
will be added here once rights-clean images have been sourced and logged."

All photographs are in Wikimedia Commons category
"Östergötlands runinskrifter 136 (Rökstenen)" (243 files; Category:Rökstenen is an
empty redirect to it). Licences below were read on each file page on 2026-11-08.

## Addendum 2026-11-09 — east-view check
- File:Rokstenen east view.jpg (Xauxa, 19 Jul 2009) was opened today: its page
  shows the same multi-licence pattern as the west view, but the licence names
  were not readable in the page text extraction, so NO licence is claimed for
  it here. It also shows the front face (same densely inscribed face as the
  "framsida" photograph), so it is not a narrow-side candidate anyway.

## Honest gaps
- Second narrow side: only ONE narrow-side photograph is licence-verified so far.
  The category holds more candidates whose file pages were listed but NOT opened:
  Achird's "höger smalsida" / "vänster smalsida" series (3968–3971, 3978–3984) and
  "Rökstenen kortsida N.jpg" / "kortsida S.jpg". One more licence check closes this.
- East/west = front/back mapping is a visual comparison of the images, not a
  statement on the file pages: the east view and the "framsida" photo show the same
  densely inscribed face; the west view shows the opposite face.
- ~150 Swedish National Heritage Board (KMB) archive photos sit in the same
  category; their individual licences were not checked and none are used here.
