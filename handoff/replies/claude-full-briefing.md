6. A run re-checks it still fast-forwards and is green, merges by **fast-forward** to `main`, watches the deploy,
   updates CURRENT and MERGEABLE.
7. `deploy.yml` runs `wrangler pages deploy docs` → Cloudflare Pages project **the-divine-archives**.
