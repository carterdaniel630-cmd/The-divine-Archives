# THE REWORK STANDARD — standing order for all armory rounds
Written by Muse at Carter's direction, 2026-10-21. Travels with every armory shipment. Binding on the build loop.

## The rule
No rework ships worse than what it replaces. Every armory piece arrives with Muse's Carter-approved build and its saved rendering. That approved build is the FLOOR for that piece — the rework must beat the build in hand, not the idea of the piece. Carter's standing directive stands: Muse-side work is a starting point to surpass, never a final product — and never a license to regress.

## The five gates (a piece is not mergeable until all five pass)
1. **Floor in hand.** The round ships the approved build file + rendering for every piece. A rework started from a description alone is invalid; restart it from the build.
2. **Side-by-side proof.** Each reworked piece returns with same-angle captures — approved build vs rework — and a short plain list of what is better (likeness, materials, light, depth, performance). Not visibly better = not done; it goes back with the comparison attached as the rejection note.
3. **No-backwards checklist (any failure fails the piece, however pretty):**
   - Inscriptions and letters stay exact to the documented record — nothing restored that the record doesn't show, nothing dropped.
   - The plaque keeps its full honest text: contested claims, forgery labels, losses, and caveats stay in, unshortened.
   - Materials read true on a phone screen, which runs darker than a monitor: metals read as their metal, stone as its stone (the Copper Scroll / Pilate Stone lessons).
   - Phone tier holds: light version loads and runs on a Galaxy-class phone; rich tier for computer/headset; nothing animated that the visitor hasn't reached.
   - The piece stays true 3D — holdable, rotatable, inspectable. No flat paintings standing in for objects.
4. **Auditor signs the round.** The round's auditor report (coverage: source and rendered) accompanies the mergeable list. Round one does not merge until the outstanding auditor-proof report has landed and Carter has seen it.
5. **Carter merges.** As always: completed + up to standard + Carter's approval of that specific merge. Rounds merge as rounds; the mergeable list (handoff/replies/MERGEABLE.md) carries the side-by-side links per piece.

## Rejection path
A piece that fails any gate returns to the loop with the failing evidence attached (comparison captures + the checklist line it broke). Two failures on the same piece escalate to Carter with both attempts shown — he rules whether the approved Muse build ships as-is instead.

## Scope
Applies to every armory round from the first shipment onward: relics now, characters and rooms when Carter opens those lines.
