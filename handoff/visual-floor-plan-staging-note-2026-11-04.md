## The plan's five lifts (summarised faithfully from the plan)
1. **THE INPUT STANDARD** (atlas's duty; effective immediately, costs the
   loop nothing): every visual order the loop receives carries the true
   source or an explicit "no true source — reconstruction" label; a
   standing bench build from atlas; the spec (measurements, materials,
   attested vs reconstructed, the close-zoom requirement); and Carter's
   relevant verdicts quoted, not paraphrased. An order missing any of
   these does not travel.
2. **THE VISUAL FOUNDATION KIT** (a build item for the loop): one shared
   kit in the production repo that every visual build stands on —
   lighting rigs (the graded setups, darkness grade for the Galaxy
   phone), the materials library (bronze, gold, worked stone, aged
   parchment, ceramic, wood — tuned once, reused everywhere), camera and
   scale rules (the anti-stick-figure standard), the ground system, and
   figure and surface standards (figures as figures, surfaces
   un-repeated, distinct room identity). See the slot proposal below.
3. **THE RENDERED-PROOF GATE** (process change; takes effect for visual
   PRs once staged): merge-on-green gains one condition for VISUAL work
   — screenshots of the actual build, phone width AND close zoom on the
   piece's hero element, rendered and attached to the PR; the
   independent review checks them against the bench, the true source,
   and the benchmark grade; visible drift is a finding, and findings
   block merge exactly as code findings do.
4. **TRUE-SOURCE CONNECTIONS** (through the Import Guard, one at a
   time): candidate published open-access scan sources (e.g. the
   Smithsonian's, the Met's, the British Museum's published collection)
   are listed in the plan as candidates only. NO connection is made by
   this staging; each candidate, when its turn comes, goes through the
   Import Guard whole — read line by line, its bubble written first,
   Carter's approval on the specific connection.
5. **THE STANDARDS WHERE HE STANDS** (this staging itself): the plan,
   the Cinematic Floor document, and the presence and wall-writing
   standards in their short forms, staged into the loop's channel so the
   builder reads them mid-build.
