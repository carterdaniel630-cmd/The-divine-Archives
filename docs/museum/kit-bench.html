What this bench is for

Every room in the museum and every Pilgrimage site will be built from one shared kit: the same tuned materials (worked stone, bronze, gold, parchment, ceramic, wood), the same graded lights, the same ground and the same human scale. This bench shows the kit by itself, so it can be judged before anything is built on it.

Each surface varies over metres as well as over its own tile, so a wall or floor no longer shows one pattern stamped across it. The "Phone" grade lifts the shadows so a dim room still reads on a phone. The real test is a walk on a phone, not this screen.

These are the archive's own materials, tuned to read like the real ones. They are not scans of any object. The grey column is a person-height marker (1.7 m) for scale, and appears only on benches.
