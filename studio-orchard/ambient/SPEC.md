# Ambient line — SPEC (auto-parallel test case for full autonomy)

**Role:** the low-risk line that runs *alongside* Pip's Orchard and serves as the **graduation test
for autonomy C** (full auto-post). If a few ambient batches run clean under review (A), Carter
graduates this line to auto — proving the pipeline before any character/brand line goes hands-off.

## What it is
Long-form **ambient / relaxation** content for the Studio Orchard YouTube (and Shorts/TikTok teasers):
- **Sleep** — rain, fireplace, night-forest, soft synth pads (1–3 hr loops)
- **Ocean** — waves, tide, gentle storm (1–3 hr loops)
- Later: focus/study, cozy-café, nature-walk ASMR

## Why it's the right test
- **Low brand/factual risk** — no character likeness, no claims, generic nature themes → a bad post
  costs little (unlike a Pip or Divine Archives post).
- **Templated + repeatable** — same format every time → easy to automate and QC.
- **Real revenue path** — long-watch-time ambient is a known YouTube-monetization niche; complements
  the core without competing for the Pip audience.

## Pipeline fit (same queue, different media)
```
pick theme + length  →  assemble loop (audio bed + slow visual)  →  thumbnail + title + desc
   →  queue (A) / or auto (C once graduated)  →  YouTube upload via Metricool/API
```

## 🔴 Blockers before this can actually produce (flag)
- **Media generation/assets** — needs royalty-free or original audio + visual sources and a render
  step (hours of video). CC can script titles/desc/thumbnails + assemble from provided assets, but
  **can't originate hours of licensed audio/video here.** Need: an asset source + a render approach.
- **YouTube upload** — needs channel access via Metricool/API (same as the Metricool blocker).
- **Copyright** — every audio/visual source must be cleared (original or properly licensed); this is
  a hard rule before anything uploads. No unlicensed music/footage.
