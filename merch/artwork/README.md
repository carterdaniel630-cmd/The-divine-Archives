# Merch symbol artwork

Finished symbol art lives here, one pair per symbol slug. The Divine Archives
runs a **hybrid** aesthetic (approved by Carter, 2026-08): two renders per
symbol, one for the website and one for physical merch.

## Dual-track naming convention

| File | Track | Aesthetic | Consumed by |
|---|---|---|---|
| `<slug>.svg` | On-site symbol | **Gold linework** — `currentColor`, 120×120 era-emblem convention (matches the site's 9 era emblems) | the website / symbol library |
| `<slug>.png` | Physical merch | **Parchment / "Gilded Vellum"** — bronze/copper on aged vellum, illuminated-manuscript style (see `AESTHETIC.md`) | the Printify merch agent |

The merch agent's `findArtwork()` resolves extensions in the order
`.png → .svg → .jpg → …`, so when both files exist for a slug it deterministically
picks the **`.png` (parchment)** render for products. The `.svg` (gold) is left
for on-site use and is never sent to Printify. Keep this convention for every new
symbol so the two tracks never diverge.
